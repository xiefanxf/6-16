# 普通 AVG 玩家视角审查

本轮审查目标：不改核心设定，只修正试玩时容易产生“作者在硬切章节”或“音乐在原地打转”的地方。

## 已修正

- 第二章证言选择后，原流程会直接进入全部角色证词。新增过桥句，让玩家理解“先问谁”只是撬开沉默的第一步，后续证言会顺势展开。
- 第三章进入凛身份揭示前，新增事实卡到“凛自己是谁”的过桥句，降低章节切换突兀感。
- 终章新增事实卡背面确认句，让最后选择前的情绪落点更清楚。
- `reconstruction-corrective` 增加记忆音效触发，让遥的关键纠正不再只靠文字出现。
- 音乐从实时程序化循环升级为真实音频资产：雨声独立循环，四类 BGM 按剧情模式交叉淡入，事件音效使用独立文件。

## 2026-07-09 追加审查

- 序章从初醒、确认身份到第一次调查过快。新增教室小动作、试门、第一次调查后的自动贩卖机与回教室段落，让玩家有时间观察七人的普通反应。
- 第一章从资料室对质硬切到旧连廊。新增整理资料、午间空教室和 16:16 前靠近旧楼的过桥段，让悠真离开后的沉默落地。
- 第二章七人证词仍像清单。新增每段证言前后的日常动作：播放器、相机背带、袖口旧疤、复印件折线、正式材料顺序、生日卡胶带，用普通物件承接情绪。
- 第三章凛身份揭示前新增“写不出生日”的日常动作，避免玩家只通过设定说明理解她的不存在。
- 第四章事故重演前新增站位和脚步声，重演后新增“旁边的人没有松一口气”，避免责任归因读起来像解题按钮。
- 终章选择前新增晨光、课桌划痕、粉笔灰、冷咖啡等普通细节，让结局选择从推理收束转向生活恢复。

## 2026-07-12 加载与视觉表示审查

- HTML 首屏继续优先加载轻量 `classroom-preview.jpg`，同时高优先级预载正式教室背景，避免标题页从 preview 切到高清背景时出现长时间空白。
- HTML 低优先级预取资料室、旧连廊和最早出现的凛/悠真立绘；React 标题页空闲时继续预热全部背景和全部立绘。
- 正文推进时预热接下来十行可能用到的场景和立绘，降低首次切到资料室、旧连廊或角色立绘时的突兀加载。
- 立绘图片使用 eager 加载、async 解码，并在失败时隐藏图片节点，避免显示浏览器断图图标。
- 媒体检查脚本扩展为验证 HTML preload/prefetch、全部背景图解码、全部立绘解码、音频资源、广播女声无立绘和点击推进边界。

## 2026-07-19 节奏复审

- 最大突兀点不是缺少剧情信息，而是大段时间跳跃缺少“玩家能感到时间经过”的动作。补充 11:00 到 16:16、18:16 到午夜、证言之间、身份揭示到红伞、事故重演到事实卡之间的等待段。
- 第一次调查分支原本在教室背景下直接写主教学楼/校门/广播室经历，视觉上容易像硬切失败。改为“回到教室后复述结果”，让背景和文本一致。
- 第二章证词之间加入便签、相机、门边等待等班会式动作，减少“七个人排队交代罪责”的清单感。
- 第四章责任重演后加入轮流站位和反复修正动作，让事实卡出现前有一段角色主动面对责任的过程。

## 保留观察

- 当前音源为本地代码生成，优势是版权和发布稳定；如果要进一步接近商业成品，下一轮应替换同名资产为外部 AI 或作曲师产出的母带。
- 立绘仍保持当前生成式 PNG 版本；广播女声无实体立绘，符合“校园广播/系统声音”的非实体设定。
- 点击推进已限制在文字区域，背景点击保持 inert，选项区域不会被正文推进逻辑吞掉。
